金融法規　期中題庫找題目

單元 03　·　34 題

金融體系、市場與資訊不對稱

比較銀行與市場如何取得資訊，並分清交易前的選擇問題和交易後的行為問題。

題 008 #

根據講義中「法律起源」的研究，下列哪一類國家的資本市場（直接金融）通常較為發達？

  1. A法國民法系國家
  2. B習慣法（Common law）國家
  3. C計畫經濟國家
  4. D以農業為主的國家
  5. E沒有中央銀行的國家
顯示答案與解析隱藏答案與解析
答案　B　習慣法（Common law）國家

講義的法律起源比較指向一項經驗關聯：普通法（common law）國家的資本市場，相對法國民法傳統國家通常較發達。這是跨國資料的比較，不代表有普通法就必然以直接金融為主。

簡報依據　《國際金融的整合與分離_4》，PDF 第 4 頁。

題 010 #

下列關於「信用配給」的敘述，何者正確？

  1. A資金供不應求時，銀行必然持續提高利率直到市場結清
  2. B信用配給是因中央銀行實施選擇性信用管制所造成
  3. C信用配給只發生在資本市場，不會發生在銀行放款
  4. D銀行可能維持較低利率並直接拒絕部分申貸者，以避免高利率引來高風險借款人
  5. E以上皆是
顯示答案與解析隱藏答案與解析
答案　D　銀行可能維持較低利率並直接拒絕部分申貸者，以避免高利率引來高風險借款人

若銀行看不清借款人風險，提高利率可能讓低風險者退出，反而留下願意承擔高息的高風險者。銀行預期回收未必隨利率上升，便可能不再加價，而直接限制核貸量；這是資訊不對稱造成的信用配給，不等於央行的行政管制。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 38 頁。

題 011 #

下列何者有助於降低借貸關係中的資訊不對稱問題？

  1. A要求借款人提供抵押品或擔保
  2. B在貸款合約中限制資金用途
  3. C公司債約定分年攤還本金，而非到期一次還本
  4. D銀行透過聯合徵信中心查核借款人的信用紀錄
  5. E以上皆是
顯示答案與解析隱藏答案與解析
答案　E　以上皆是

信用紀錄有助事前辨別風險；抵押或擔保讓違約有代價；限制資金用途抑制挪用；分年還本則讓債權人較早看到履約情形並降低到期集中風險。四種做法分別改善篩選、監督或還款誘因，故選以上皆是。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 36–38 頁。

題 015 #

下列關於以銀行為基礎（Bank-based）與以市場為基礎（Market-based）的金融體系之敘述，何者正確？

  1. A以銀行為基礎的金融體系主要依賴公開市場資訊進行企業監督，因此較有利於投資人即時取得企業資訊。
  2. B以市場為基礎的金融體系能透過銀行與企業建立長期關係，降低貸款後的道德風險。
  3. C以銀行為基礎的金融體系能利用長期的企業關係取得資訊，並透過監督企業降低資訊不對稱問題。
  4. D以市場為基礎的金融體系較適合經濟發展程度較低的國家，因為企業能透過資本市場直接取得資金，降低對金融中介機構的依賴。
  5. E銀行與市場為基礎的金融體系具有明確的優劣之分，一國只要選擇其中一種，就能有效促進經濟成長。
顯示答案與解析隱藏答案與解析
答案　C　以銀行為基礎的金融體系能利用長期的企業關係取得資訊，並透過監督企業降低資訊不對稱問題。

銀行長期接觸企業，可從帳戶與授信往來取得未公開資訊，貸後也能持續監督。因此用長期銀企關係降低資訊不對稱是銀行導向的機制。市場則常利用揭露、價格與交易傳遞資訊；兩種體系都可能有利有弊。

簡報依據　《國際金融的整合與分離_4》，PDF 第 7、10–13 頁。

題 018 #

關於金融體系的金融服務觀點，下列敘述何者正確？

  1. A銀行與金融市場的發展程度，直接決定一國金融體系提供金融服務的效率。
  2. B金融中介機構與金融市場的制度安排，主要目的在於取代彼此的功能，以提升金融體系效率。
  3. C金融體系應優先發展資本市場，使企業降低對銀行融資的依賴。
  4. D金融體系的核心在於提供完善的金融服務，金融中介機構與市場的制度形式則可隨環境變化而調整。
  5. E金融服務的提供主要仰賴金融機構，金融市場僅負責提供資金交易的場所。
顯示答案與解析隱藏答案與解析
答案　D　金融體系的核心在於提供完善的金融服務，金融中介機構與市場的制度形式則可隨環境變化而調整。

金融服務觀點先問企業與家庭是否能取得資金、管理風險、傳遞資訊，而非先選銀行或市場作唯一答案。技術與法律環境改變後，承擔同一服務的機構可以更替；評價重點在服務品質及成本。

簡報依據　《國際金融的整合與分離_4》，PDF 第 13 頁。

題 023 #

關於資訊不對稱，下列敘述何者錯誤？

  1. A逆向選擇發生於交易之前
  2. B面對超額資金需求，銀行一定會調高利率而非實施信用配給
  3. C道德風險發生於交易之後
  4. D抵押品與限制性條款可用來降低資訊不對稱的問題
  5. E存款人無法分辨銀行好壞，可能引發擠兌
顯示答案與解析隱藏答案與解析
答案　B　面對超額資金需求，銀行一定會調高利率而非實施信用配給

銀行提高利率除了增加契約利息，也可能改變申貸者組成及違約率。當高息反而嚇退安全客戶時，直接拒絕部分貸款比繼續加息合理，所以「一定調高利率」是錯誤的絕對敘述。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 36–38 頁。

題 024 #

關於活期儲蓄存款，下列敘述何者正確？

  1. A營利事業可以開立
  2. B依法不計利息
  3. C僅限自然人及非營利法人開立
  4. D存款不足時會發生退票
  5. E牌告利率通常低於活期存款
顯示答案與解析隱藏答案與解析
答案　C　僅限自然人及非營利法人開立

依簡報的三類帳戶比較，活期儲蓄存款對象為自然人及非營利法人，且有計息。營利事業的日常週轉可用一般活期存款；不計息及退票是支票存款的辨識線索，不能移植到活儲。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 13 頁。

題 025 #

資訊不對稱（Asymmetric Information）是金融市場的重要問題，下列何者最能說明其意義？

  1. A交易雙方擁有完全相同的資訊
  2. B金融機構不需要取得任何客戶資料
  3. C交易雙方掌握的資訊不相同，可能影響交易決策與結果
  4. D所有金融商品的資訊都由政府統一提供
  5. E市場參與者無法使用任何金融資訊
顯示答案與解析隱藏答案與解析
答案　C　交易雙方掌握的資訊不相同，可能影響交易決策與結果

資訊不對稱指交易雙方對風險或行為掌握得不同，例如借款人較銀行清楚資金將如何使用。關鍵是資訊分布不均，不是雙方都不知道未來；它可在交易前造成逆向選擇，也可在交易後造成道德風險。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 36 頁。

題 045 #

關於銀行導向（Bank-based）與市場導向（Market-based）的金融體系，下列敘述何者正確？

  1. A銀行導向的金融體系主要依賴公開市場資訊，因此投資人必須自行蒐集企業資訊。
  2. B市場導向的金融體系主要透過銀行與企業建立長期借貸關係，以取得企業的私人資訊。
  3. C銀行導向的金融體系能透過與企業建立長期關係，取得企業資訊並監督企業經營。
  4. D市場導向的金融體系完全不需要金融機構參與資金配置。
  5. E銀行導向與市場導向的金融體系具有相同的資訊取得方式，因此兩者並無明顯差異。
顯示答案與解析隱藏答案與解析
答案　C　銀行導向的金融體系能透過與企業建立長期關係，取得企業資訊並監督企業經營。

銀行重複與企業往來，可以累積不易由公開市場看到的資訊；在放款後也有持續監督資金運用的動機。這解釋了銀行導向體系的優點，並不意味它沒有資訊租或危機風險。

簡報依據　《國際金融的整合與分離_4》，PDF 第 7–10 頁。

題 055 #

關於以銀行為基礎（Bank-based）與以市場為基礎（Market-based）的金融體系，下列何者敘述錯誤？

  1. A銀行可透過與企業建立長期關係，降低資訊不對稱問題
  2. B市場為基礎的金融體系有助於透過企業購併改善公司治理
  3. C銀行為基礎的金融體系可透過監督企業降低道德風險
  4. D市場為基礎的金融體系完全不會發生金融危機
  5. E銀行與資本市場皆可能對經濟成長產生正面貢獻
顯示答案與解析隱藏答案與解析
答案　D　市場為基礎的金融體系完全不會發生金融危機

市場可以提高流動性、傳遞價格資訊並促進資源配置，但市場價格也會大幅波動，甚至出現流動性枯竭。制度選擇有取捨，不能從市場導向的優點推出「完全不會發生金融危機」，故 D 錯。

簡報依據　《國際金融的整合與分離_4》，PDF 第 10–13 頁。

題 059 #

以下哪個是資訊不對稱引發的事前難題

  1. A逆向選擇
  2. B道德風險
  3. C選擇困難
  4. D市場崩盤
  5. E擠退風險
顯示答案與解析隱藏答案與解析
答案　A　逆向選擇

放款前，銀行難以辨識申貸者的真實風險，高風險者反而可能更積極申貸，叫作逆向選擇。若是借到款後才改做高風險投資，風險來自後續行為，才是道德風險。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 36 頁。

題 084 #

下列關於我國數位存款帳戶分類與身分驗證（KYC）規定的敘述，何者錯誤？

  1. A第一類數位帳戶通常須以自然人憑證搭配視訊驗證，或採臨櫃驗證
  2. B第二類數位帳戶係使用開戶人在本行既有之臨櫃帳戶進行身分驗證
  3. C第三類數位帳戶使用他行臨櫃帳戶或特定信用卡進行驗證，其非約定轉帳額度通常最低
  4. D主管機關目前全面開放民眾跨行以第一類數位帳戶直接再開立他行第三類數位帳戶
  5. E數位存款帳戶在法律上的存款性質主要歸屬於活期儲蓄存款
顯示答案與解析隱藏答案與解析
答案　D　主管機關目前全面開放民眾跨行以第一類數位帳戶直接再開立他行第三類數位帳戶

本題應揪出「全面開放」：開戶分類取決於本人查驗、既有往來關係與驗證強度，不能只因名下已有他行第一類數位戶，就自動取得跨行另開第三類的資格。各類另有不同的交易範圍。A 至 C 只描述常見驗證路徑，不代表每一類只有一種驗證方式。

簡報依據　《金融監理與創新_3》，PDF 第 51–53 頁。

題 087 #

借款人取得銀行貸款後，把資金拿去從事高風險投資，把潛在損失轉嫁給放款人。這屬於哪一種問題？

  1. A事前的逆向選擇（Adverse Selection）
  2. B事後的道德風險（Moral Hazard）
  3. C事前的道德風險
  4. D事後的逆向選擇
  5. E信用配給（Credit Rationing）
顯示答案與解析隱藏答案與解析
答案　B　事後的道德風險（Moral Hazard）

關鍵是時間點：交易已成立，借款人之後提高資金用途的風險，成功時自己保有上檔、失敗時債權人分攤損失，形成道德風險。這和銀行在核貸前就分不清借款人類型的逆向選擇不同。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 36–38 頁。

題 088 #

關於以銀行為基礎（bank-based）和以市場為基礎（market-based）的金融體系，下列敘述何者正確？

  1. A法國民法系（French civil law）國家的資本市場，通常比習慣法國家發達
  2. B習慣法（Common law）國家通常有較發達的金融市場體系
  3. C支持 bank-based 的觀點認為，流動性高的市場較能強化公司治理
  4. D支持 market-based 的觀點認為，銀行與企業的長期關係最能促進創新

顯示答案與解析隱藏答案與解析
答案　B　習慣法（Common law）國家通常有較發達的金融市場體系

法系起源研究比較國家間的金融結構，在講義列出的經驗關係中，習慣法國家的市場型融資相對較發達。這是跨國趨勢，不表示所有同一法系國家都有相同制度，也不是判斷兩種體系絕對孰優的定理。

題 095 #

關於以銀行為基礎（Bank-based）與以市場為基礎（Market-based）兩大金融體系之學術文獻爭論與台灣實務，下列敘述何者錯誤？

  1. A根據法系起源研究，英美習慣法國家通常比法國大陸法系國家擁有更發達的資本市場體系

  3. CHellwig (1991) 與 Rajan (1992) 批評，以銀行為基礎的體系容易讓銀行向企業萃取資訊租 （Informational Rents），保護既有銀企關係而阻撓創新與競爭

  5. E台灣屬於典型的 Bank-based 體系；金管會指定之6家系統性重要銀行須額外提列2%法定資本與2%內部管理資本，並可享有轉投資金融相關事業5,000萬元以下自動核准等「胡蘿蔔」優惠
顯示答案與解析隱藏答案與解析
答案　D　Gambacorta et al. (2014) 實證發現，在爆發金融危機時，銀行體系能發揮強大的吸震功能，因此金融危機對 Bank-based 體系的經濟衰退衝擊僅有 Market-based 體系的三分之一

關係型銀行在一般衰退可依長期資訊續貸，幫企業吸收衝擊；若危機本身傷害銀行資產負債表，銀行可能被迫縮減貸款，反而放大衰退。D 把一般衰退的緩衝效果移植到金融危機，並顛倒講義中銀行型和市場型的比較。

簡報依據　《國際金融的整合與分離_4》，PDF 第 7–12 頁。

答案　A　銀行與企業建立長期關係，有助於取得資訊及監督企業。

銀行與企業往來多次，能觀察現金流、累積非公開資訊，並在放款後持續監督。因此關係融資能減少借貸雙方的資訊落差。股票與債券的公開定價則是市場型體系的比較優勢。

簡報依據　《國際金融的整合與分離_4》，PDF 第 7–11 頁。

題 177 #

依央行金融統計說明，下列何者未併入國內金融機構部門，而是視為民營企業部門處理？

  2. B信用合作社
  3. C票券金融公司
  4. D農漁會信用部

題 184 #

某企業為籌措營運資金，同時發行公司債與普通股。當企業經營不善、可分配資產有限時，兩類投資人對企業資產的請求權存在差異。依據金融資產的基本分類與經濟特性，下列敘述何者最為適當？

  1. A公司債與普通股均屬權益工具，兩者差異僅在於收益分配方式不同。
  2. B公司債持有人通常享有約定本息及受償順位的債權請求權，普通股股東則享有剩餘請求權，兩者價值均與未來預期現金利益有關。
  3. C普通股股東享有固定順位請求權，因此在企業清算時原則上優先於公司債持有人受償。
  4. D金融資產必須具有實體憑證才能成立，以電子紀錄方式發行的股票或債券不屬於金融資產。
  5. E債權與權益請求權的受償順位完全相同，因此無法用來區分金融資產種類。
顯示答案與解析隱藏答案與解析
答案　B　公司債持有人通常享有約定本息及受償順位的債權請求權，普通股股東則享有剩餘請求權，兩者價值均與未來預期現金利益有關。

債券持有人依約有本息請求權，清償順位通常在普通股東之前；股東則承擔剩餘風險，只有付清較優先的請求後才能分到剩餘資產。順位較高不等於公司違約時一定能足額受償。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 29–30 頁。

題 186 #

在一般經濟衰退及金融危機期間，銀行與資本市場可能發揮不同的風險緩衝功能。關於銀行導向（Bank-based）與市場導向（Market-based）金融體系的比較，下列敘述何者最為適當？

  1. A銀行導向金融體系在任何經濟衰退中都比市場導向金融體系更具韌性，因此應全面以銀行取代資本市場。
  2. B銀行通常會在一般經濟衰退時加速抽離資金，但在金融危機期間則能完全吸收系統性風險。
  3. C銀行在一般經濟衰退時可能發揮緩衝作用，但金融危機發生時其吸收衝擊的能力可能減弱，因此兩種金融體系不具有絕對優劣。
  4. D市場導向金融體系不需要金融中介機構，因此不會受到金融危機與資產價格下跌的影響。
  5. E金融活動越發達，對經濟成長的貢獻便必然持續增加，不可能出現貢獻有限甚至為負的情況。
顯示答案與解析隱藏答案與解析
答案　C　銀行在一般經濟衰退時可能發揮緩衝作用，但金融危機發生時其吸收衝擊的能力可能減弱，因此兩種金融體系不具有絕對優劣。

一般衰退時，關係銀行可以繼續供應信用，減緩企業融資中斷。但若衝擊來自銀行本身，資本受損就可能迫使銀行同步收縮信用。哪種體系較能緩衝衝擊，要看危機源頭；銀行或市場都不是永遠較安全。

簡報依據　《國際金融的整合與分離_4》，PDF 第 7–12 頁。
