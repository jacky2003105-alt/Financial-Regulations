題 036 #

關於台新金控與新光金控合併過程中引發的「外匯價格變動準備金（外價金）」會計與監理爭議，下列敘述何者正確？

  1. A外價金在會計處理上屬於資產項目，其餘額減少會直接降低公司淨值
  2. B合併後新光人壽帳列外價金減少 475 億元，導致帳面負債增加
  3. C金管會保險局認為外價金為法定準備金，要求新光人壽必須回補減少的 475 億元
  4. D金管會完全同意金控業者將外價金直接沖銷為營業外收入，無須回補
  5. E以上敘述皆正確
顯示答案與解析隱藏答案與解析
答案　C　金管會保險局認為外價金為法定準備金，要求新光人壽必須回補減少的 475 億元

本案主管機關把外匯價格變動準備金視為須依規定提列、收回的法定準備；新壽因而增提約 475 億元回補。準備金本身列在負債項下，不能因合併後曾出現帳面減少，就當成可自由收回的收益。此處談的是該案準備金處理，不等於對另列資產的會計判斷一併作結論。

補充依據　個案報導（中央社）

題 062 #

根據金管會對金融機構合併案的新規定，公開收購應以何種方式作為對價？

  1. A僅能以普通股作為對價
  2. B僅能以特別股作為對價
  3. C必須以現金及股票各半支付
  4. D應以現金為對價
  5. E可完全由收購方自行決定，不受限制
顯示答案與解析隱藏答案與解析
答案　D　應以現金為對價

就金控依法公開收購公開發行公司股份的特定投資程序，規範要求以現金為對價，故選 D。這是針對該程序的特別要求，不代表所有併購或一般公開收購都只能付現金；法定合併與公開收購也不是同一項程序。

題 063 #

根據國泰投信關係人違規事件，旗下基金違規買進世芯-KY股票的主要原因為何？

  1. A基金經理人未取得客戶投資授權
  2. B投信端未落實利害關係人資料申報與建檔控管
  3. C金管會未即時公布股票交易限制
  4. D銀行未依法提列存款準備金
  5. E基金投資海外股票超過法定比例
顯示答案與解析隱藏答案與解析
答案　B　投信端未落實利害關係人資料申報與建檔控管

投信必須先取得並更新董事等人的利害關係資料，再讓交易前檢核辨認不得投資的標的。國泰投信未確實落實申報、維護和內部控管，造成關係資訊無法有效攔阻交易。問題屬利益衝突管理，不是客戶授權、海外配置或存款準備率。

題 064 #

下列何者屬於《銀行防範理財專員挪用客戶款項相關內控作業原則》中的行為牽制防線？

  1. A落實強制休假
  2. B落實職務輪調
  3. C禁止代為保管客戶財物
  4. D定期監控理專關聯帳戶金流
  5. E落實內部稽核
顯示答案與解析隱藏答案與解析
答案　C　禁止代為保管客戶財物

「禁止代為保管」直接限制理專能做的事：不讓理專同時掌握存摺、印鑑或交易憑證，減少未授權交易的機會。輪調與休假屬人事調控，監測帳戶與稽核則是偵測異常，和題目所問的行為禁令有別。

補充依據　官方原文

題 093 #

檢視近年台灣發生的重大金融機構內控失靈裁罰案，下列案例與違規缺失之配對何者錯誤？

  1. A國泰投信案：因高層兼任世芯-KY獨董卻發生系統資訊斷層未通報建檔，導致旗下基金與全委帳戶違規買進利害關係公司股票，除補償約9.44億元外，更被要求依「責任地圖」究責
  2. B房貸行員收受佣金案：多家銀行行員將未指定代書之房貸案集中轉介特定地政士並私下收受回扣，涉犯《銀行法》第35條，促使銀行業建立「代書輪派制」與大數據集中度監控
  3. C台新銀行理專侵占案：理專趁家訪偷卡並在洽談室調包新舊提款卡盜領高齡客戶款項，總行法遵主管因「第一時間主動向金管會通報重大偶發事件」，獲得金管會減輕處分免予罰鍰
  4. D理專十誡防線：包含強制休假、職務輪調、禁止代客保管/交易、禁止自製對帳單及防堵客戶聯絡資料與理專相同等內控原則
  5. E國泰投信業務限縮處分：金管會除開罰法定最高額度合計600萬元外，並祭出1年內禁止申請募集海外有價證券基金等三項核心業務凍結處分
顯示答案與解析隱藏答案與解析
答案　C　台新銀行理專侵占案：理專趁家訪偷卡並在洽談室調包新舊提款卡盜領高齡客戶款項，總行法遵主管因「第一時間主動向金管會通報重大偶發事件」，獲得金管會減輕處分免予罰鍰

C 把通報事實顛倒。金管會於 2026 年 5 月 26 日指出，台新銀行理專挪用高齡客戶款項，銀行未依規定通報重大偶發事件，遭罰 1,400 萬元，並受業務限制。即使已和解，仍要依規定通報；內部自行處理不能取代外部監理。

題 125 #

下列何者違反「理專十誡」的規範?

  1. A落實強制休假
  2. B定期職務輪調
  3. C代替客戶執行交易
  4. D建立獨立對帳機制
  5. E落實內部稽核
顯示答案與解析隱藏答案與解析
答案　C　代替客戶執行交易

理專可說明商品、接收及依程序轉交客戶指示，但不得取代客戶作交易決定，或取得客戶密碼代為操作。強制休假、輪調、獨立對帳及稽核是防止挪用長期不被發現的控制；題目要選的是破壞控制的行為。

題 126 #

ICS新制主要強調以何種方式衡量保險公司的資產與負債？

  1. A歷史成本
  2. B公允價值
  3. C帳面價值
  4. D稅務價值
  5. E名目價值
顯示答案與解析隱藏答案與解析
答案　B　公允價值

選項中「公允價值」最接近。ICS 用市場調整評價衡量經濟上的資產與負債，使利率等風險反映在監理資產負債表。嚴格說不是每項都照搬會計公允價值；一般不可複製的保險負債，以現時估計加上超額邊際（MOCE）衡量。

題 127 #

金管會合併新規，何者符合規定？

  1. A公開收購得以股票作為對價
  2. B首次投資其他金控20%即可符合新門檻
  3. C首次投資應先取得獨立專家意見並提報審計委員會
  4. D公開收購條件可在金管會同意前公布
  5. E投資遭否決後三個月即可重新申請
顯示答案與解析隱藏答案與解析
答案　C　最接近的選項。首次投資應先取得獨立專家意見並提報審計委員會

C 最接近，但程序順序要說準確。《金融控股公司投資管理辦法》第3條規定，所列首次投資先提報審計委員會審議，委員會審議時委請外部獨立專家協助評估，再由董事會決議。不能把專家意見當成替代審計委員會的事前許可。

題 128 #

理專侵占客戶款項案中，下列何者最符合監理要求？

  1. A損失金額較小即可免予通報
  2. B應監控異常交易並依規定通報重大事件
  3. C經客戶同意即可由理專保管提款卡
  4. D內部稽核可完全取代法遵主管責任
  5. E僅需追究理專個人責任，銀行無須負責
顯示答案與解析隱藏答案與解析
答案　B　應監控異常交易並依規定通報重大事件

理專挪用的危險在於同一人可能同時接觸指示、帳戶與對帳資料。銀行應有獨立查核、異常交易偵測與通報機制；發現符合法定通報條件的重大事件應依規定通報。事後補錢或以個人行為為由不查，都沒有修復控制缺口。

題 138 #

關於我國金融控股公司及金融機構的經營現況，下列敘述何者正確？

  1. A富邦金控與中國信託金控皆屬家族型金控，且兩者均以銀行及保險為主要業務，但中國信託金控的資產規模高於富邦金控。
  2. B國票金融控股公司以證券業務為主要特色，其所有權結構則屬於專業經理人型態。
  3. C元大金融控股公司屬於家族型金控，並以證券業務為主要經營特色。
  4. D台灣的信用合作社與一般商業銀行皆具有吸收存款及辦理放款的功能，因此兩者在法律地位及適用的金融監理規範上並無差異。
  5. E台灣金融機構透過存款保險制度保障存款人權益，因此銀行即使發生經營危機，存款人的所有存款仍可獲得全額保障。
顯示答案與解析隱藏答案與解析
答案　C　元大金融控股公司屬於家族型金控，並以證券業務為主要經營特色。

依本課簡報的金控比較表，元大列為家族型且以證券業務見長；同表富邦資產規模高於中信。這是簡報所列時點的業務特色與所有權分類，不是由法律永久指定。吸收存款的共同功能也不等於適用相同組織法規。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 7 頁。

題 178 #

雙重槓桿比率(DLR)之計算方式為何？

  1. A金控對子公司長期股權投資／總資產
  2. B金控對子公司長期股權投資／淨值
  3. C子公司淨值／金控淨值
  4. D金控淨值／子公司長期股權投資
  5. E金控總負債／淨值
顯示答案與解析隱藏答案與解析
答案　B　金控對子公司長期股權投資／淨值

金控母公司可以借款，再把這筆錢以股權形式投進子公司。因此監理上看「對子公司長期股權投資」相對於「母公司淨值」有多大。例如投資 120 億、淨值 100 億，DLR 為 120%。把分母換成總資產或只看總負債，衡量的就不是同一件事。
