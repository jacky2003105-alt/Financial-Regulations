題 003 #

下列何者並非金融監理沙盒應注意的基本原則？

  1. A鼓勵金融科技創新
  2. B保障金融消費者權益
  3. C建立完善風險控管措施

題 006 #

下列關於克里斯汀生「破壞式創新」的敘述，何者正確？

  1. A破壞者一開始在主流指標上表現就比既有業者好
  2. B破壞式創新主要服務主流市場的高端客戶
  3. C破壞式創新通常以較低價格或較簡單的方式切入低階市場或新興市場
  4. D旗艦手機每年升級規格是破壞式創新的典型例子
  5. E破壞式創新的概念最早出自熊彼得1911年的《經濟發展理論》
顯示答案與解析隱藏答案與解析
答案　C　破壞式創新通常以較低價格或較簡單的方式切入低階市場或新興市場

題 016 #

某銀行原本提供企業客戶客製化的利率交換契約，協助企業管理利率風險。隨著市場參與者增加，該類商品逐漸標準化，並開始在交易市場中流通。根據 Merton and Bodie 的金融創新螺旋理論，下列敘述何者最適當？

原題未列 B 選項，以下保留原有字母。

  1. A金融市場與金融中介機構在特定時點可能存在競爭關係，但隨著金融商品與交易方式演變，兩者也可能呈現動態上的互補關係，使原先由金融中介機構提供的商品逐漸轉由市場交易。
  2. C金融商品標準化後，市場交易的效率通常會提高，因此金融中介機構原先提供該商品的功能將不再具有經濟價值。
  3. D金融商品由金融中介機構轉移至市場交易，代表兩者原本具有的互補關係逐漸消失，市場將取代金融中介機構。
  4. E金融創新螺旋主要反映金融中介機構將市場上既有的標準化商品重新設計為客製化商品，以降低交易市場的競爭程度。
顯示答案與解析隱藏答案與解析
答案　A　金融市場與金融中介機構在特定時點可能存在競爭關係，但隨著金融商品與交易方式演變，兩者也可能呈現動態上的互補關係，使原先由金融中介機構提供的商品逐漸轉由市場交易。

客製利率交換初期需要銀行設計、媒合；需求擴大且契約標準化後，集中市場才有足夠交易量提高流動性。爭取同一業務時兩者競爭，但中介的設計又為市場開路，故會動態互補，不是市場永久消滅中介。

簡報依據　《金融監理與創新_3_New》，PDF 第 20 頁。

題 019 #

根據 Tufano（2002）對金融創新原因的整理，下列何者並非其所提出的可能原因？

  1. A透過金融創新填補不完整市場，以滿足原有金融商品無法充分提供的需求。
  2. B藉由創新金融商品或制度，降低代理問題及資訊不對稱所產生的影響。
  3. C透過金融科技與制度創新，降低交易、搜尋及行銷成本。
  4. D因應全球化及風險環境變化，發展新的金融商品與服務。
  5. E透過金融創新降低金融機構對外部資金的依賴，進而減少金融市場在資金配置中的角色。
顯示答案與解析隱藏答案與解析
答案　E　透過金融創新降低金融機構對外部資金的依賴，進而減少金融市場在資金配置中的角色。

Tufano 討論創新的動因，包括補足不完備市場、降低交易成本、處理資訊不對稱、回應稅制與管制等。E 把「削弱市場配置資金的角色」當成一般目標，但開發新工具反而可能讓更多交易進入市場，所以不在所列動因中。

  3. C金融監理沙盒的適用對象以既有金融機構為主，非金融業者原則上不適用。
  4. D金融監理沙盒的實驗成果若證明具有市場可行性，即代表業者已取得正式經營該項業務的資格。

題 026 #

Silber 對金融創新的解釋中，Shadow Price（影子價格）主要與下列哪一項概念有關？

  1. A金融機構的實際股票價格
  2. B金融機構受到限制時，突破限制所產生的潛在成本
  3. C政府公布的市場利率
  4. D投資人購買金融商品的交易價格
  5. E金融機構的股東權益價值
顯示答案與解析隱藏答案與解析
答案　B　最接近的選項。金融機構受到限制時，突破限制所產生的潛在成本

B 最接近，但影子價格的精確定義是：限制放寬一單位，最適目標值能改善多少。它反映「限制仍然存在」的邊際機會成本，而非突破限制要支付的開發費。影子價格愈高，找到替代做法的潛在收益愈大。

簡報依據　《金融監理與創新_3_New》，PDF 第 5–6 頁。

題 030 #

金融業者因既有管制而開發替代商品，主管機關隨後調整規範，業者再尋求新的因應方式。下列解釋何者最適當？

  1. A屬金融創新螺旋，重點在金融市場與中介機構交替推出商品。
  2. B屬管制辯證，呈現管制、業者因應與規範調整的動態互動。
  3. C屬影子價格理論，表示管制限制越緊，創新誘因必然越低。
  4. D屬功能觀點，表示金融功能必須由原有機構持續提供。
  5. E屬監理沙盒，業者開發替代商品即取得法規豁免。
顯示答案與解析隱藏答案與解析
答案　B　屬管制辯證，呈現管制、業者因應與規範調整的動態互動。

題中反覆出現的是「政府設限制 → 業者尋求替代 → 主管機關因應新做法再調整」，符合 Kane 的管制辯證。創新螺旋強調中介與市場互補，影子價格則衡量約束的代價，兩者不是這個動態互動的名稱。

簡報依據　《金融監理與創新_3_New》，PDF 第 7–10 頁。

題 031 #

  1. A甲使用新科技，應歸類為新興市場破壞。
  2. B乙初期功能較少，應歸類為維持性創新。
  3. C乙服務既有市場的客戶，因此不屬破壞式創新。
  4. D依金融功能觀點，乙須取得與甲相同的組織形式才能提供理財功能。

答案　E　甲較符合維持性創新，乙較符合低階市場破壞的發展路徑。

題 034 #

根據 Merton 提出的金融體系「功能觀點」（Functional Perspective），下列關於金融功能與機構的敘述何者正確？

  1. A金融機構的組織形式比金融體系所提供的金融功能更具長期穩定性
  2. B金融機構形式決定了金融功能，即「功能隨機構而生」
  3. C金融體系的 6 大核心功能會隨時間與跨國界而頻繁改變
  4. D金融功能比金融機構更具穩定性，且機構形式是隨金融功能而演進（Institutional forms follow functions）
  5. E以上敘述皆非
顯示答案與解析隱藏答案與解析
答案　D　金融功能比金融機構更具穩定性，且機構形式是隨金融功能而演進（Institutional forms follow functions）

支付、融資和風險分擔等需求通常比特定公司的壽命長。當技術與交易成本改變，提供功能的組織會跟著調整，這就是「機構形式追隨功能」；不代表功能永遠不變，也不是必須保存原有組織。

簡報依據　《金融監理與創新_3_New》，PDF 第 14–17 頁。

  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　C　將原本複雜昂貴的產品變簡單與便攜，瞄準過去無力消費的「非消費者」（Nonconsumers）

新市場破壞的第一批使用者原先不是消費者，例如負擔不起或不會使用昂貴複雜的方案。當商品變簡單、可負擔，便創造原來沒有的使用機會。若本來已是用戶，只想用更低價取得夠用的功能，才較接近低階市場破壞。

簡報依據　《破壞式創新的討論_講義》，PDF 第 3–4 頁。

題 171 #

依據金融體系之「功能視角」（Functional Perspective）理論，下列敘述何者正確？

  1. A金融機構型態比金融功能更加穩定且永恆不變
  2. B金融機構的組織型態係依循其所擔負的金融功能而演進
  3. C金融體系的核心功能僅包含支付清算與吸收存款，不包含風險管理與處理資訊不對稱
  4. D金融功能會隨著時間與跨國界而快速改變，而機構型態則保持不變
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　B　金融機構的組織型態係依循其所擔負的金融功能而演進

功能觀點先問「資金如何移轉、風險如何分攤」，再看誰來提供服務。支付可以從分行移到手機，支付功能仍在，因此組織會隨功能需求改變。若反過來認為固定機構決定所有金融功能，就把兩個觀點顛倒了。

簡報依據　《金融監理與創新_3_New》，PDF 第 14–17 頁。

題 179 #

下列何者「不屬於」金融體系之六大核心功能？

  1. A制定貨幣政策
  2. B清算與結算(交收)
  3. C匯集與分割資源
  4. D管理風險
  5. E處理委託代理與資訊不對稱問題
顯示答案與解析隱藏答案與解析
答案　A　制定貨幣政策

六項功能在說金融體系替資金供需雙方做什麼：支付清算、匯集資源、跨時空移轉資源、管理風險、提供價格資訊與處理誘因問題。制定貨幣政策是中央銀行的公共職權，不是六項市場功能之一。

簡報依據　《金融監理與創新_3_New》，PDF 第 16 頁。

題 185 #

1970年代末至1980年代初，美國處於高通貨膨脹環境，銀行受到Regulation Q等規範限制，而貨幣市場基金（MMF）逐漸發展，並出現金融脫媒（Disintermediation）現象。依據Kane的管制辯證（Regulatory Dialectic）觀點，下列何者最能解釋此一現象？

  1. A金融機構受到管制後，市場參與者將停止尋找替代性金融服務，因此金融創新不會再出現。
  2. B貨幣市場基金的出現代表銀行完全不再具有資金中介功能，金融監理也因而失去必要性。
  3. C金融脫媒主要反映銀行與貨幣市場基金之間的所有權合併，而非資金流向改變。
  4. D既有銀行管制與市場環境的變化，可能促使資金流向替代性金融商品，形成管制套利與金融脫媒，並引發後續監理調整。
  5. E管制辯證認為，金融監理一旦建立便不應調整，金融業也不會因應監理限制改變經營方式。
顯示答案與解析隱藏答案與解析
答案　D　既有銀行管制與市場環境的變化，可能促使資金流向替代性金融商品，形成管制套利與金融脫媒，並引發後續監理調整。

當市場利率因通膨上升而銀行存款利率受 Regulation Q 限制，銀行存款對投資人較不具吸引力。資金轉向能提供市場收益的替代工具，誘使金融業設計新產品。關鍵是管制與市場價格間的落差，而非科技進步突然取代銀行。

簡報依據　《金融監理與創新_3_New》，PDF 第 7、10–11 頁。

題 189 #

關於金融體系的功能觀點（Functional Perspective）與機構觀點（Institutional Perspective），以及克萊頓·克里斯汀生（Clayton Christensen）的破壞性創新理論，下列敘述何者錯誤？

  1. A功能觀點認為「功能恆久遠，機構非必然」，金融功能比起金融機構具有更高的穩定性
  2. BMerton & Bodie 提出的「金融創新螺旋」（Financial Innovation Spiral）指出，金融中介機構與組織化市場在靜態上相互競爭，但在動態上具有互補性
  3. C在金融創新螺旋中，由中介機構初始提供的客製化產品，隨著產品標準化與市場效率提升，最終會轉移至公開市場交易
  4. D破壞性創新（Disruptive Innovation）通常從主流市場中最具利潤的高端客戶（High end of the market）切入，再逐步向下侵蝕低端市場
  5. E根據金融體系的六大核心功能，處理解決委託人-代理人（Principal-Agent）與資訊不對稱問題屬於其一
顯示答案與解析隱藏答案與解析
答案　D　破壞性創新（Disruptive Innovation）通常從主流市場中最具利潤的高端客戶（High end of the market）切入，再逐步向下侵蝕低端市場

本題問錯誤敘述。破壞者通常先接住被主流忽略的低階客戶，或讓原本買不起的人開始消費，再逐步改善產品進入主流。直接搶攻最賺錢的高階客戶，不符合這兩條典型路徑。市場與中介機構的動態互補則是另一個理論「金融創新螺旋」。

簡報依據　《破壞式創新的討論_講義》，PDF 第 3–5 頁。
