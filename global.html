題 012 #

美國「銀行控股公司(BHC)」的出現，主要是為了規避下列哪兩項法律限制？

  1. AGlass-Steagall Act的跨業限制與McFadden Act的跨州限制
  2. BDodd-Frank Act的Volcker Rule與Basel III的資本要求
  3. CRegulation Q的利率上限與存款保險制度
  4. D金融控股公司法與銀行法
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　A　Glass-Steagall Act的跨業限制與McFadden Act的跨州限制

選項中 A 對應兩種歷史限制：Glass–Steagall 涉及商業銀行和證券業務的分隔，McFadden 涉及分行地域限制。持股控制不同銀行，是以不同法人擴張經營的方式。更精確地說，控股公司早已存在，不能把兩法說成它首次出現的唯一原因，也不能說控股即可免除法律限制。

答案　B　評估全球金融體系的脆弱性，並促進各國監理機關合作

題 035 #

關於巴塞爾銀行監理委員會（BCBS）推出的 Basel III 資本適足監理標準相較於 Basel II 之改革，下列敘述何者正確？

  1. A普通股權益（Common Equity Tier 1）最小資本要求由 2% 提高至 4.5%
  2. B第一類資本（Tier 1 Capital）最小要求調降至 3%
  3. C總資本（Total Capital）最小要求調降至 6%
  4. DBasel III 取消了所有的資本防衛/保守緩衝（Capital Conservation Buffer）機制
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　A　普通股權益（Common Equity Tier 1）最小資本要求由 2% 提高至 4.5%

此題比較的是普通股權益最低要求，占風險加權資產的比率由 2% 提高到 4.5%。再加 2.5% 資本保留緩衝才是 7%，不要把「最低要求」和「最低要求加緩衝」混算。Basel III 也引入流動性要求。

簡報依據　《國際金融的整合與分離_4》，PDF 第 46 頁。

答案　D　D-SIBs 申請新種業務時可優先核准，且 3 年試辦期間屆滿後，無重大違失者申請延長可採自動核准。

題 046 #

關於2008年全球金融海嘯的形成與風險傳播，下列敘述何者最為適當？

  1. A次級房貸主要提供給信用條件較佳的借款人，因此違約風險相對較低。
  2. B次級房貸經過證券化等金融操作後，相關風險透過金融商品交易擴散至不同金融機構與投資人。
  3. C金融海嘯的發生主要是因為各國政府停止金融機構之間的交易，導致資金無法流通。
  4. D金融商品經過信用評等機構評等後，就能確保投資人不會承受違約風險。
  5. E2008年金融海嘯僅影響美國房地產市場，並未對其他國家的金融體系造成影響。
顯示答案與解析隱藏答案與解析
答案　B　次級房貸經過證券化等金融操作後，相關風險透過金融商品交易擴散至不同金融機構與投資人。

次級房貸證券化後，一批貸款的現金流被包裝、轉售給不同持有人。當房價下跌、違約增加，依賴這些現金流的證券也會受損；金融機構彼此持有或融資，使風險跨機構、跨國傳開。風險被重新分配，並未被消除。

簡報依據　《國際金融的整合與分離_4》，PDF 第 22–24 頁。

  1. A調高普通股權益等高品質資本的法定最低比率要求
  2. B建立資本保留緩衝（Capital Conservation Buffer）
  3. C建立逆景氣循環緩衝（Countercyclical Capital Buffer）
  4. D全面廢除流動性覆蓋比率（LCR）與淨穩定融資比率（NSFR）

答案　D　全面廢除流動性覆蓋比率（LCR）與淨穩定融資比率（NSFR）

題 100 #

金融海嘯後，Basel III 除了提高資本要求以外，還新增了哪兩項流動性監理指標？

  1. A資本適足率、槓桿比率
  2. B存放比率、逾期放款比率
  3. C流動性覆蓋比率（LCR）、淨穩定資金比率（NSFR）
  4. D雙重槓桿比率（DLR）、資本適足率
  5. E資產報酬率（ROA）、股東權益報酬率（ROE）
顯示答案與解析隱藏答案與解析
答案　C　流動性覆蓋比率（LCR）、淨穩定資金比率（NSFR）

LCR（流動性覆蓋比率）比較高品質流動資產與 30 日壓力情境的淨現金流出；NSFR（淨穩定資金比率）比較可用與所需的穩定資金，著眼較長期的融資結構。兩者分別處理短期支付能力與較長期資金錯配，不是兩種資本比率。

簡報依據　《國際金融的整合與分離_4》，PDF 第 46 頁。

  2. B亞洲金融風暴，亞洲國家貨幣大幅貶值，造成全球金融體系連鎖危機
  3. C歐洲主權債務危機，各國政府債務違約，引發全球金融市場恐慌
  4. D美國次級房貸市場過度擴張，金融機構大量承作高風險房貸，並透過金融商品證券化擴散風險
  5. E南非幣因國際資金大量外流而大幅貶值，引發新興市場貨幣危機。
顯示答案與解析隱藏答案與解析
答案　D　美國次級房貸市場過度擴張，金融機構大量承作高風險房貸，並透過金融商品證券化擴散風險

次級房貸擴張讓信用條件較弱的借款人也能大量借款；房貸證券化又把現金流與風險分散到其他機構。房價反轉、違約率上升後，投資人對證券與交易對手失去信心，使局部房貸問題傳成跨市場危機。科技泡沫與亞洲金融風暴屬不同事件。

題 107 #

關於2008年金融海嘯的發生與後續檢討，下列敘述何者為非?

  1. A房貸機構將次級房貸包裝成複雜的「資產證卷化」商品(如MBS)販售，是危機擴大的原因之一
  2. B危機發生前，各國監理機關大多僅關注在個別金融機構上，忽略了系統性風險，導致海嘯席捲全球
  3. C為了防範未然，海嘯後國際推行了「巴賽爾協定 III(Basel III)」，主要是為了降低銀行的資本適足率要求，讓銀行有更多資金放貸
  4. D海嘯後美國通過了《陶德-法蘭克法案》(Dodd-Frank Act)，其中包含的伏克爾規則(Volcker Rule)，限制銀行以一定的比例自有資本投資於避險與私募股權基金
  5. E海嘯後美國設立了「消費者金融保護局(CFPB)」，專責保護金融消費者的權益
顯示答案與解析隱藏答案與解析
答案　C　為了防範未然，海嘯後國際推行了「巴賽爾協定 III(Basel III)」，主要是為了降低銀行的資本適足率要求，讓銀行有更多資金放貸

海嘯顯示高槓桿及流動性不足會擴大損失；Basel III 的回應是提升高品質資本與建立緩衝，並加強流動性要求。它不是靠降低資本適足標準讓銀行多放款，故 C 為錯誤敘述。

簡報依據　《國際金融的整合與分離_4》，PDF 第 25、46 頁。

題 112 #

  1. A只關注大型金融機構的獲利能力
  2. B只監督個別金融機構，不考慮整體金融體系
  3. C同時考慮個別金融機構與整體金融體系的影響
  4. D減少各國金融監理機關之間的合作
  5. E完全取消金融市場的監管
顯示答案與解析隱藏答案與解析
答案　C　同時考慮個別金融機構與整體金融體系的影響

一家銀行為自保而出售資產可能合理，但許多銀行同時出售，會把市場價格壓低，使全體損失增加。因此危機後的監理要兼看單家機構健全與全體金融體系的連動，不能只逐家檢查或只看獲利。

簡報依據　《國際金融的整合與分離_4》，PDF 第 47–48 頁。

題 174 #

2008 年金融海嘯後，陶德－法蘭克法案（Dodd-Frank Act）中的伏克爾規則（Volcker Rule），主要目的為何？

  1. A鼓勵銀行增加對避險基金的投資。
  2. B限制銀行使用自有資金進行特定自營交易及投資避險基金、私募股權基金。
  3. C取消銀行資本適足率的要求。
  4. D鼓勵銀行承擔更高的投資風險。
顯示答案與解析隱藏答案與解析
答案　B　限制銀行使用自有資金進行特定自營交易及投資避險基金、私募股權基金。
