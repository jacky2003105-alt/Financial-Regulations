金融法規　期中題庫找題目

單元 02　·　27 題

金融監理架構與工具

先找監理的目標與對象，再判斷是誰執行、管個別機構還是整體系統。

題 007 #

英國2013年起實施雙峰監理體制，其中負責「行為監理」（第二峰）的機關是：

  1. A英格蘭銀行附屬審慎監理局（PRA）
  2. B金融行為監管局（FCA）
  3. C澳洲審慎監管局（APRA）
  4. D荷蘭中央銀行（DNB）
  5. E紐西蘭儲備銀行（RBNZ）
顯示答案與解析隱藏答案與解析
答案　B　金融行為監管局（FCA）

英國雙峰分工中，FCA 主管業務行為，例如銷售方式及消費者保護；PRA 負責其監理對象的審慎健全。題目問第二峰，不能因 PRA 同樣是監理者就選它。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 009 #

關於我國中央銀行與金管會在金融監理上的分工，下列敘述何者正確？

  1. A金管會主要負責總體審慎監理(macro-prudential)
  2. B中央銀行主要負責個別金融機構日常營運的安全性與健全性
  3. C在國際組織中，IMF扮演的角色與我國中央銀行的總體審慎角色較為相近
  4. D中央銀行平時每年對各金控進行例行性金融檢查
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　C　在國際組織中，IMF扮演的角色與我國中央銀行的總體審慎角色較為相近

C 比較的是觀察層次：IMF 監測一國經濟金融穩定，較接近央行關注整體金融體系的面向。這不是宣稱兩者法定權限相同。個別金融機構的日常安全健全及一般金融檢查，不能一概歸給央行。

簡報依據　《國際金融的整合與分離_4》，PDF 第 44、47 頁。

題 022 #

依監理目標分設兩個監理機關，一個負責審慎監理（安全與健全），另一個負責業務行為監理，此種金融監理模式稱為：

  1. A機構型
  2. B功能型
  3. C整合型
  4. D雙峰型
  5. E二元機構型
顯示答案與解析隱藏答案與解析
答案　D　雙峰型

雙峰是按「目標」切分：審慎監理關注資本、清償及風險承受能力，行為監理關注業務如何對待客戶。兩峰均可跨銀行、證券和保險；若依業別切分，才是部門型。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 41、44 頁。

題 029 #

某國將跨銀行、證券及保險業的清償能力監理由甲機關負責，商品銷售與消費者保護由乙機關負責。下列判斷何者正確？

  1. A屬機構別監理，因各業者均有法定身分。
  2. B屬功能別監理，因各類金融商品分由不同機關監理。
  3. C屬整合型監理，因監理範圍涵蓋三種金融業。
  4. D屬雙峰體制，其分類關鍵為監理目標的分工。
  5. E須確認甲機關是否隸屬央行，才能判定是否為雙峰體制。
顯示答案與解析隱藏答案與解析
答案　D　屬雙峰體制，其分類關鍵為監理目標的分工。

甲看三業的清償能力，乙看三業如何銷售與保護客戶。兩者都跨業，真正區分甲乙的是監理目的，故為雙峰。跨業本身不足以判成單一整合機構，也無須先知道甲是否隸屬央行。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 44 頁。

題 032 #

各銀行均符合個別資本要求，卻持有相似資產，並在市場下跌時同步出售，進一步壓低價格。下列監理判斷何者最適當？

  1. A應納入總體審慎監理，評估共同曝險與同步出售造成的系統性風險。
  2. B應僅提高商品資訊揭露，因價格下跌主要屬消費者保護問題。
  3. C應僅逐家檢查資本比率，因共同持有資產不影響體系穩定。
  4. D應改採市場為基礎的金融體系，以排除共同曝險引發的危機。
  5. E應以存款保險取代資本與流動性監理，避免銀行同步出售資產。
顯示答案與解析隱藏答案與解析
答案　A　應納入總體審慎監理，評估共同曝險與同步出售造成的系統性風險。

各銀行個別達到資本標準，仍可能因資產高度相似而同步拋售；一家的賣出壓低價格，會讓其他銀行也產生損失。這種共同曝險與回饋是整體體系的問題，需要總體審慎觀點，不能只逐家查資本適足。

簡報依據　《國際金融的整合與分離_4》，PDF 第 25、47 頁。

題 033 #

關於各國金融監理主要模式（Regulating approaches）的分類與特色，下列敘述何者正確？

  1. A機構監理模式（Institutional Approach）是以金融機構發行的商品種類作為劃分監理機關之依據
  2. B雙峰監理模式（Twin Peaks Approach）將監理職能劃分為「安全審慎監理」與「業務行為監理」兩大核心，代表國家如澳洲與荷蘭
  3. C整合監理模式（Integrated Approach）是指由中央銀行獨立運作經營行為監理，並由財政部負責審慎監理
  4. D功能監理模式（Functional Approach）僅適用於美國，其他國家皆採用單一整合監理
  5. E美國目前採用單一完全整合（Integrated）的監理架構
顯示答案與解析隱藏答案與解析
答案　B　雙峰監理模式（Twin Peaks Approach）將監理職能劃分為「安全審慎監理」與「業務行為監理」兩大核心，代表國家如澳洲與荷蘭

澳洲與荷蘭是講義列出的雙峰案例：一峰負責機構的安全健全，另一峰負責業務行為與消費者保護。判斷雙峰應看監理目標是否分立，不是單看有無兩個機構名稱。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 057 #

以下哪個局不隸屬於金管會？

  1. A檢查局
  2. B保險局
  3. C外匯局
  4. D證期局
  5. E銀行局
顯示答案與解析隱藏答案與解析
答案　C　外匯局

金管會的四個業務局為銀行局、證券期貨局、保險局及檢查局。外匯局屬中央銀行，負責外匯管理與調度，所以分辨關鍵是機關隸屬，而不是業務是否與金融有關。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 3 頁。

題 066 #

關於國際金融監理之「雙峰體制（Twin Peaks Model）」，下列敘述何者正確？

  1. A將監理功能分為「審慎監理」與「行為監理」兩大面向
  2. B澳洲為完全獨立型雙峰體制代表，由APRA負責審慎監管、ASIC負責市場行為監管
  3. C英國與荷蘭屬於央行整合型雙峰體制，將審慎監理交由央行或其附屬機構
  4. D雙峰體制之設立目的之一在於獨立處理金融消費者保護與市場行為規範
  5. E以上敘述皆正確
顯示答案與解析隱藏答案與解析
答案　E　以上敘述皆正確

先辨第一峰看機構能否穩健履約，第二峰看銷售、市場行為與消費者保護。澳洲例為 APRA／ASIC；英國由央行體系內的 PRA 與獨立 FCA 分工；荷蘭例為 DNB／AFM。A 至 D 均符合講義的分類，故選 E。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 070 #

關於金融監理的雙峰體制（Twin Peaks Model），下列何者敘述正確？

  1. A雙峰體制係將銀行監理與證券監理分別交由不同機關負責
  2. B雙峰體制主要區分為審慎監理及行為監理兩大功能
  3. C澳洲採行央行整合型雙峰體制，由中央銀行直接負責審慎監理
  4. D英國採行完全獨立型雙峰體制，審慎監理機關與中央銀行完全分離
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　B　雙峰體制主要區分為審慎監理及行為監理兩大功能

雙峰的「二」是兩種監理目的：財務是否穩健，以及市場行為是否公平。同一家銀行可能同時接受兩座峰的監理；並非因為銀行、證券或保險隸屬不同行業就各設一峰。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 077 #

以下哪些為「金融監理參與者」：

  1. A國際金融機構
  2. B一般金融機構
  3. C立法者
  4. D執法者
  5. E以上皆是
顯示答案與解析隱藏答案與解析
答案　E　以上皆是

監理過程包含決策、制訂規範、執行及檢視結果。國際機構協調標準，立法者訂法律，執法者監督落實，金融機構也因內控、遵循及回饋參與其中。參與不等於都擁有公權力，所以選 E。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 39 頁。

題 081 #

關於國際金融監理體系中的「雙峰監理模式（Twin Peaks Model）」，下列敘述何者錯誤？

  1. A雙峰體制將監理核心劃分為「審慎監理」與「業務／行為監理」兩大面向
  2. B澳洲為雙峰體制的始祖國家之一，審慎監管由APRA負責，行為監管由ASIC負責
  3. C英國在2008年金融海嘯後進行改革，將PRA設於英格蘭銀行附屬機構下，FCA則掌管行為監理
  4. D荷蘭的雙峰體制中，審慎監理由荷蘭中央銀行（DNB）負責
  5. E雙峰模式屬於完全依金融機構法人型態（如銀行、保險、證券）分別設立專屬單一主管機關的部門型監理（Sectoral Model）
顯示答案與解析隱藏答案與解析
答案　E　雙峰模式屬於完全依金融機構法人型態（如銀行、保險、證券）分別設立專屬單一主管機關的部門型監理（Sectoral Model）

雙峰按監理目標分，部門型按銀行、保險、證券等業別分。澳洲、英國與荷蘭雖然將審慎機關放在不同組織位置，都不改變這個分類標準。E 把兩套分類混為一談。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 086 #

不論業者的法律地位是銀行、證券商還是保險公司，只依它「實際從事的業務」決定由哪個監理機關負責，這是哪一種監理模式？

  1. A機構型（Institutional Approach）
  2. B功能型（Functional Approach）
  3. C整合型（Integrated Approach）
  4. D雙峰型（Twin Peaks Approach）
  5. E自律型（Self-regulation）
顯示答案與解析隱藏答案與解析
答案　B　功能型（Functional Approach）

判別方式是問「依什麼分配監理者」。題幹只依實際辦理的業務，例如同類證券業務適用相同監理，不看業者是何種法人，所以是功能型；若先看是銀行還是保險公司才是機構型。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 41 頁。

題 097 #

依金管會組織法第 1 條，下列何者「不是」金融監督管理的目標？

  1. A健全金融機構業務經營
  2. B維持金融穩定
  3. C促進金融市場發展
  4. D穩定物價水準
  5. E以上皆是金管會的目標
顯示答案與解析隱藏答案與解析
答案　D　穩定物價水準

金管會組織法第1條列健全金融機構業務經營、維持金融穩定及促進金融市場發展。物價水準與整體幣值穩定較接近央行貨幣政策目標；金融穩定和物價穩定雖相關，不能把兩個機關的法定任務互換。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 2 頁。

題 105 #

某V國設立了兩種獨立的金融監管機構，一個專門負責所有金融機構的資本適足與清償能力監理，另一個專門負責所有金融機構的消費者保護與業務行為監理。請問該國的金融監理模式較符合哪一種金融監理模型的架構？

  1. A機構型(Institutional Model)/部門型(Sectoral Model)
  2. B整合型(Integrated Model)
  3. C雙峰型(Twin Peaks Model)
  4. D功能型(Functional Model)
  5. E獨特型(Unique Model)
顯示答案與解析隱藏答案與解析
答案　C　雙峰型(Twin Peaks Model)

兩機關都跨銀行、證券、保險，但甲只管資本、償付能力，乙只管市場行為及消費者保護。這種按監理目標分工的雙峰模式，和單純按機構業別各自設局不同。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 106 #

某I國設立了數種不同的金融監管機構。該國決定在劃分監理權責時，不考慮該機構的法律身分，純粹依據各家金融機構實際從事的業務性質來決定由哪一個機關監理，請問該國的金融監理模式較符合哪一種金融監理模型的架構？

  1. A機構型(Institutional Model)/部門型(Sectoral Model)
  2. B整合型(Integrated Model)
  3. C雙峰型(Twin Peaks Model)
  4. D功能型(Functional Model)
  5. E獨特型(Unique Model)
顯示答案與解析隱藏答案與解析
答案　D　功能型(Functional Model)

「不考慮法律身分，依實際業務」就是功能型的辨識條件。機構型先認定業者身分；整合型由單一機關跨業監理。不能只看到「數個機關」就選雙峰，還要知道劃分依據。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 41 頁。

題 113 #

依據我國《金融監督管理委員會組織法》第1條，下列何者並非金融監督管理委員會的主要目標？

  1. A健全金融機構業務經營
  2. B維持金融穩定
  3. C促進金融市場發展
  4. D確保所有金融機構均能獲利
  5. E以上皆為金融監督管理委員會的主要目標
顯示答案與解析隱藏答案與解析
答案　D　確保所有金融機構均能獲利

第1條設立金管會的目的，是健全金融機構業務經營、維持金融穩定與促進金融市場發展。健全經營是要求公司有能力管理風險；保證每一家獲利則是替股東承擔經營結果，並非監理承諾。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 2 頁。

題 118 #

有關全球雙峰監理體制之敘述，下列何者正確？

  1. A澳洲於1998年實施雙峰體制，為雙峰體制之始祖，屬於兩峰皆與中央銀行完全分離之完全獨立型
  2. B英國於2013年改制後，行為監理由英格蘭銀行附屬之審慎監理局(PRA)負責
  3. C完全獨立型之雙峰體制下，中央銀行仍負責日常金融機構之審慎監理
  4. D荷蘭之審慎監理機關為金融市場局(AFM)
  5. E以上皆非
顯示答案與解析隱藏答案與解析
答案　A　澳洲於1998年實施雙峰體制，為雙峰體制之始祖，屬於兩峰皆與中央銀行完全分離之完全獨立型

雙峰依監理目的分工。澳洲以 APRA 負責審慎監理、ASIC 負責市場行為；依講義分類，兩機關都在央行之外。這與把審慎監理設在央行內部的制度不同，也不表示澳洲央行沒有金融穩定職責。

簡報依據　《補充金融體制》，PDF 第 1 頁。

題 122 #

關於全球常見金融監理體制的分類，下列敘述何者「錯誤」？

  1. A「機構型監理」是依照金融機構所屬的產業別（銀行、證券、保險）分別指派專責主管機關進行管理
  2. B「功能型監理」強調不論由哪種機構提供，只要本質相同的金融業務與產品，就應適用相同的法規標準
  3. C傳統「一元化單一監理體制」，是由單一主管機關統合負責全體金融業的各項監理工作
  4. D台灣目前由金融監督管理委員會（金管會）統籌管理銀行、證券期貨及保險，屬於將「審慎監理」與「市場行為」切分為兩個獨立機關的雙峰體制
顯示答案與解析隱藏答案與解析
答案　D　台灣目前由金融監督管理委員會（金管會）統籌管理銀行、證券期貨及保險，屬於將「審慎監理」與「市場行為」切分為兩個獨立機關的雙峰體制

金管會跨銀行、證券期貨及保險進行監理；雙峰則要求按目標，把審慎監理與行為監理分配給不同機關。央行同時負有金融穩定職責，並不自動使臺灣的制度變成雙峰。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 3、43–44 頁。

題 134 #

關於金融監理的「雙峰模式」（Twin Peaks），下列敘述何者正確？

  1. A依金融機構的法律身分，分別設置銀行、證券及保險監理機關
  2. B依監理目標分工，由不同機關分別負責審慎監理與業務行為監理
  3. C由單一機關統一負責所有金融業的健全性與業務行為監理
  4. D以金融機構的資產規模為標準，分別設置大型與小型機構監理機關
  5. E依交易是否涉及外匯，區分國內金融與國際金融監理機關
顯示答案與解析隱藏答案與解析
答案　B　依監理目標分工，由不同機關分別負責審慎監理與業務行為監理

雙峰的分界是目的：一峰看機構能否吸收損失並履約，一峰看客戶是否獲公平對待及市場行為是否妥當。一家銀行可同時受兩峰監理；不是只把銀行和證券分到不同機關。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 41、44 頁。

  4. D檢查局

題 159 #

某銀行因為經營不善而倒閉，存款人可透過存款保險制度，在法定保障範圍內獲得賠償。此制度屬於下列何者金融監理措施?

  1. A事前風險預防
  2. B事前信用審查
  3. C金融市場價格管制
  4. D事後補償機制
  5. E金融機構資本適足性管理
顯示答案與解析隱藏答案與解析
答案　D　事後補償機制

題幹問的是銀行倒閉後，存款人在保障範圍內獲賠的這個環節，因此屬事後補償。資本適足與授信審查是在出事前限制風險。存保制度本身也能在事前安定信心，但不改變本題賠付發生的時間點。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 24、38 頁。

題 163 #

關於「部門型（Sectoral Model）」金融監理模型的特徵，下列敘述何者正確？

  1. A分為銀行、保險、證券等由各自獨立的主管機關負責該領域之健全性與行為監理
  2. B由單一通用主管機關跨產業統一監督所有金融服務業
  3. C依據其所從事之金融業務性質劃分各自的主管機關
  4. D依監理目的將監理權限劃分為審慎健全與營業行為兩大主管機關
  5. E將所有金融機構按資產規模大小劃分，資產大於一定門檻者由中央銀行直接監理，其餘由地方政府監理
顯示答案與解析隱藏答案與解析
答案　A　分為銀行、保險、證券等由各自獨立的主管機關負責該領域之健全性與行為監理

部門型以銀行、保險、證券等業別劃分主管機關，各自在所屬部門兼顧健全性與行為。雙峰雖也是多個機關，但它是依兩種監理目的切分，不是依金融業別切分。

題 165 #

  1. A健全金融機構業務經營
  2. B維持金融穩定
  3. C促進金融市場發展
  4. D確保所有金融機構獲得穩定獲利
  5. E以上皆為金融監督管理委員會的主要目標
顯示答案與解析隱藏答案與解析
答案　D　確保所有金融機構獲得穩定獲利

《金融監督管理委員會組織法》第1條所處理的是健全金融機構業務經營、維持金融穩定與促進金融市場發展。健全是能承受風險與正常履約，並非主管機關保證每一家機構都穩定獲利。

題 175 #

關於個體審慎監理（Microprudential Supervision）與總體審慎監理（Macroprudential Supervision），下列何者正確？

  1. A個體審慎監理關注整體金融體系，總體審慎監理只關注單一銀行。
  2. B兩者都只關注個別金融機構的獲利能力。
  3. C個體審慎監理關注個別金融機構的安全與穩健，總體審慎監理則關注整體金融體系的系統性風險。
  4. D總體審慎監理主要負責保護銀行股東的投資報酬。
顯示答案與解析隱藏答案與解析
答案　C　個體審慎監理關注個別金融機構的安全與穩健，總體審慎監理則關注整體金融體系的系統性風險。

個體審慎監理問一家機構出事時是否承受得住；總體審慎監理問許多機構的行為合起來是否讓整個體系更脆弱。例如各家銀行各自賣債降低風險，若同時賣出卻壓低債價，形成全體共同損失。

題 188 #

關於金融監理模型（Supervisory Models）的分類，下列各國監理體制與模型的配對及定義，何者完全正確？

  1. A雙峰型（Twin Peaks Model）：將監理機構分為審慎監理（Prudential/Solvency）與業務行為/消費者保護（Conduct of Business）兩大峰，代表國家為澳洲與荷蘭
  2. B機構型（Institutional Approach）：依據金融機構所執行的業務功能來決定監理機關，無視其法律身份，代表國家為新加坡
  3. C整合型（Integrated Model）：由單一通用監理機關統一負責所有金融業別之審慎監理與行為監理，代表國家為美國
  4. D一部門型（Sectoral Model）：由中央銀行獨佔所有銀行、證券及保險業的監理，代表國家為英國
  5. E台灣目前採行完全的雙峰型監理架構，由中央銀行專責審慎監理，金管會專責行為監理
顯示答案與解析隱藏答案與解析
答案　A　雙峰型（Twin Peaks Model）：將監理機構分為審慎監理（Prudential/Solvency）與業務行為/消費者保護（Conduct of Business）兩大峰，代表國家為澳洲與荷蘭

雙峰的分類準則是「監理目標」：一峰看機構是否健全、能否清償，另一峰看業務行為與客戶待遇，澳洲和荷蘭是講義列舉的例子。按實際業務決定監管者屬功能型；按銀行、證券、保險分工屬部門型。

簡報依據　《補充金融體制》，PDF 第 1 頁。
