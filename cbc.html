中央銀行法與貨幣政策

題 005 #

近年來針對房貸祭出「選擇性信用管制」，例如限制第二戶與高價住宅的購屋貸款成數，主要是由哪一個機關推動？

  1. A金融監督管理委員會
  2. B財政部
  3. C中央銀行
  4. D公平交易委員會
  5. E內政部
顯示答案與解析隱藏答案與解析
答案　C　中央銀行

房貸成數是貸款金額相對擔保品價值的上限。中央銀行運用選擇性信用管制，針對特定類別不動產貸款限制槓桿及信用過度集中；這和金管會日常監督個別銀行的授信及內控是不同職能。

題 037 #

根據《中央銀行法》第1條之規定，中央銀行之地位為何？

  1. A隸屬立法院的獨立財政機構
  2. B為國家銀行，隸屬行政院
  3. C屬民間經營之股份有限公司，並受財政部監督
  4. D隸屬總統府的最高貨幣主管機關
顯示答案與解析隱藏答案與解析
答案　B　為國家銀行，隸屬行政院

中央銀行法第1條處理「組織地位」：我國中央銀行為國家銀行，隸屬行政院。它有貨幣政策職責，並不因此隸屬總統府、立法院或財政部，也不是一般民營銀行。

簡報依據　《中央銀行法_2026 2》，PDF 第 4 頁。

題 039 #

根據《中央銀行法》第13條之規定，關於中華民國貨幣的敘述，下列何者正確？

  1. A貨幣由財政部統一發行
  2. B貨幣僅在臺灣本島地區具有法償效力
  3. C貨幣之印製及鑄造由財政部設廠專營
  4. D中華民國貨幣由中央銀行發行，對於境內一切支付具有法償效力
顯示答案與解析隱藏答案與解析
答案　D　中華民國貨幣由中央銀行發行，對於境內一切支付具有法償效力

中央銀行法第13條指定國幣由央行發行，且對中華民國境內一切支付具有法償效力。法償效力說的是國幣具有清償支付的法律地位，不只限於臺灣本島；印製、鑄造也不是財政部專營。

題 040 #

依據《中央銀行法》第9條之規定，中央銀行的總裁與副總裁職務及其任期為何？

  1. A總裁特任、副總裁簡任，任期均為五年，期滿得續加任命
  2. B總裁與副總裁任期均為三年，期滿不得連任
  3. C總裁由行政院院長兼任，副總裁任期四年
  4. D總裁及副總裁均為終身職，無任期限制
顯示答案與解析隱藏答案與解析
答案　A　總裁特任、副總裁簡任，任期均為五年，期滿得續加任命

依第9條，總裁一人為特任、副總裁二人為簡任，兩者任期均為五年，期滿可以續加任命。五年是每一任的期間，不代表終身職，也不是任滿後一律不得再任。

題 050 #

依據《中央銀行法》之規定，下列何者並非中央銀行經營之目標？

  1. A促進金融穩定
  2. B健全銀行業務
  3. C維護對內及對外幣值之穩定
  4. D保障金融消費者之投資收益

顯示答案與解析隱藏答案與解析

題 061 #

中央銀行實施選擇性信用管制（限貸令）的主要目的為何？

  1. A增加銀行不動產放款的獲利
  2. B限制金融機構對外匯市場的投資
  3. C改善信用資源過度集中於不動產貸款的情形

答案　C　改善信用資源過度集中於不動產貸款的情形

選擇性信用管制針對特定貸款用途或擔保品調整條件，例如降低不動產貸款成數，使借款人投入更多自有資金，並限制銀行相同類型曝險累積。降低準備率影響的是整體資金條件，不是這項工具的目的。

關於中央銀行發行貨幣的規定，下列何者正確？

  1. A只有紙幣需要發行準備
  2. B硬幣也必須提列與紙幣相同的發行準備
  3. C中央銀行不能發行紀念幣
  4. D新台幣不是法定貨幣
  5. E中央銀行不能委託其他銀行發行貨幣
顯示答案與解析隱藏答案與解析
答案　A　只有紙幣需要發行準備

依第16條，發行或委託發行貨幣須以合格資產折值十足準備，但「硬幣免提發行準備」，因此本題選 A。發行準備不是商業銀行的存款準備金；本法也明定國幣的法償效力並准許發行紀念幣。

題 182 #

依《中央銀行法》第13條規定，中華民國貨幣（國幣）是由下列哪一個機構發行？

  1. A中央銀行
  2. B交通部氣象署
  3. C台灣電力公司
  4. D台北101大樓
  5. E巷口里長辦公室
顯示答案與解析隱藏答案與解析
答案　A　中央銀行

第 13 條授予央行發行國幣的職權。第 14 條另容許必要時分區委託公營銀行代理發行，但資產及負債仍歸央行。代理機構並不因此變成法定發行權的所有人。

簡報依據　《中央銀行法_2026 2》，PDF 第 15 頁。

題 183 #

根據中央銀行發行之鈔券規格，現行流通之新臺幣「壹仟圓（1000元）」紙鈔正面圖案為小學生上課（教育），請問其主要顏色為何？

  1. A藍色
  2. B紅色
  3. C螢光粉紅色
  4. D黑白條紋
  5. E透明無色
顯示答案與解析隱藏答案與解析
答案　A　藍色

題幹用正面「小學生上課」辨識券別，問的是主色而非圖案。這張壹仟圓券的主墨色為藍，背面是玉山與帝雉；不要與紅色的壹佰圓券混淆。

簡報依據　《中央銀行法_2026 2》，PDF 第 16 頁。
