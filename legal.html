金融法制與立法程序

辨別法律與命令的位階、人民權益保障，以及覆議與復議的程序。

題 001 #

下列何者並非金融法規的主要立法目的？

  1. A維護金融市場秩序
  2. B保障金融消費者權益
  3. C促進金融市場健全發展
  4. D完全消除金融市場所有投資風險
  5. E強化金融機構監督管理
顯示答案與解析隱藏答案與解析
答案　D　完全消除金融市場所有投資風險

監理透過資訊揭露、交易規則與機構監督維持公平、效率及金融穩定。主管機關能要求業者揭露或管理風險，卻無法保證資產價格不跌；題目問「並非」，所以選完全消除風險。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 33–35 頁。

題 013 #

下列關於金融法規之立法目的及其規範內容的敘述，何者正確？

  1. A金融法規僅適用於銀行及證券商，政府與一般市場參與者不受其規範。
  2. B《銀行法》的主要目的在於保障投資人的證券交易權益，而《證券交易法》則主要保障銀行存款人的權益。
  3. C金融法規的主要目的在於促進金融機構獲利，因此不需要特別考量金融市場的公平性。
  4. D金融法規透過規範金融活動，保障存款人及投資人權益、防止系統性風險，並維護金融市場的公平與效率。
  5. E為了促進金融市場自由競爭，金融法規應避免政府介入金融市場，也不需要管理個別金融機構的健全性。
顯示答案與解析隱藏答案與解析
答案　D　金融法規透過規範金融活動，保障存款人及投資人權益、防止系統性風險，並維護金融市場的公平與效率。

存款人和投資人難以自行掌握所有資訊，金融機構的失敗又可能波及其他人；這說明為何法律同時重視公平交易、投資人保護、效率與系統穩定。規範的對象是金融活動，目的並非替個別業者保證利潤。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 33–35 頁。

題 014 #

下列關於金融法規之立法目的及其規範內容的敘述，何者正確？

  1. A金融法規主要針對金融機構進行規範，政府與其他市場參與者則依其業務性質決定是否受到相關法規約束。
  2. B《銀行法》主要著重於維護金融機構的經營穩定，而存款人權益的保障則主要由存款保險制度負責。
  3. C金融法規應優先維護金融市場的運作效率，至於市場競爭公平性及弱勢投資人保護，則屬於市場自律的範疇。
  4. D金融法規主要透過限制金融機構的業務範圍來降低市場風險，因此金融監理的重點在於個別機構，而非整體金融體系的穩定。
  5. E金融法規透過規範金融活動，保障存款人及投資人權益、防止系統性風險，並兼顧金融市場公平與經濟效率。
顯示答案與解析隱藏答案與解析
答案　E　金融法規透過規範金融活動，保障存款人及投資人權益、防止系統性風險，並兼顧金融市場公平與經濟效率。

本題要選完整描述。金融法規既規範金融活動與交易秩序，也處理市場失靈，兼顧消費者權益、金融穩定及效率。只看單一銀行或只看短期獲利，都不足以概括公共監理的目的。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 33–35 頁。

題 017 #

根據《中央法規標準法》，下列關於法律與命令的敘述，何者正確？

  1. A凡涉及人民權利義務之事項，均得由行政機關依職權發布命令規範。
  2. B法律與命令均須經立法院通過，始具有法規效力。
  3. C行政機關得依其法定職權或法律授權訂定命令，但其內容仍須符合上位法規。
  4. D命令經立法院審查通過後，其法規位階即與法律相同。
  5. E特別法與普通法發生適用競合時，應優先適用普通法。
顯示答案與解析隱藏答案與解析
答案　C　行政機關得依其法定職權或法律授權訂定命令，但其內容仍須符合上位法規。

辨別命令要分「有無訂定權」與「內容有無牴觸上位法」兩步。行政機關可依職權或法律授權訂定命令，但不能以命令取代法律保留事項，也不能牴觸憲法或法律；有權發布並不代表內容可不受限制。

簡報依據　《金融監管_intro_2026_2_New》，PDF 第 22–23 頁。

題 049 #

依據《金融消費者保護法》之規定，金融服務業與金融消費者訂立契約前，應履行下列何種義務？

  1. A充分了解金融消費者之相關資料
  2. B確認金融商品或服務符合消費者需求
  3. C充分說明金融商品及服務的重要內容
  4. D充分揭露金融商品可能產生之風險
  5. E以上皆是
顯示答案與解析隱藏答案與解析
答案　E　以上皆是

訂約前有兩組不同義務：依第9條，先了解客戶資料、判斷商品或服務是否適合；依第10條，充分說明重要內容並揭露風險。口頭宣稱「客戶自行決定」不能取代這些義務，四項都在考察範圍，故選 E。

題 051 #

依據《洗錢防制法》之規定，下列何者為金融機構應履行之義務？

  1. A確認客戶身分
  2. B留存客戶身分確認資料
  3. C審查客戶之實質受益人
  4. D對高風險客戶加強審查
  5. E以上皆是
顯示答案與解析隱藏答案與解析
答案　E　以上皆是

確認身分是為了知道交易對象，查核實質受益人則是辨認最終控制者；相關紀錄必須保存以利日後追查。風險較高時還要加強審查。這些措施共同構成風險基礎的客戶審查，並非只看一張身分證就足夠。

題 052 #

依據《保險法》之規定，下列何者符合保險利益之相關規定？

  1. A任何人均可對他人財產投保
  2. B要保人或被保險人對保險標的物無保險利益時，保險契約仍然有效
  3. C要保人對財產上之現有利益，或因財產上現有利益而生之期待利益，具有保險利益
  4. D保險利益僅適用於人身保險，不適用於財產保險
  5. E保險利益與保險契約之效力無關
顯示答案與解析隱藏答案與解析
答案　C　要保人對財產上之現有利益，或因財產上現有利益而生之期待利益，具有保險利益

保險法第14條承認兩種財產保險利益：現有的利益，以及從現有利益產生的期待利益。例如所有人對自有房屋有利益；對陌生人的財物單純希望它不受損，不能據此認定有保險利益。故 C 正確。

題 073 #

下列何者最符合金融法規的主要立法目的？

  1. A增加金融機構的獲利能力
  2. B降低政府對金融市場的介入
  3. C限制所有金融機構之間的競爭
  4. D保護投資人、維持金融穩定及促進市場效率
  5. E鼓勵金融機構承擔更高的投資風險
顯示答案與解析隱藏答案與解析
答案　D　保護投資人、維持金融穩定及促進市場效率

  1. A法律應經立法院通過，總統公布
  2. B關於人民權利、義務的事項，應以法律定之
  3. C應以法律規定的事項，不得以命令定之
  4. D法規對同一事項有特別規定者，應優先適用
  5. E下級機關訂定的命令，可以牴觸上級機關的命令

法律、命令之間有位階。命令不能牴觸憲法或法律，下級機關命令也不能牴觸上級機關命令，因此 E 錯。同一事項的特別規定優先適用，並不是授權下級命令逾越上位規範。

關於覆議與復議，下列何者正確？

  2. B立法院對自身議事決定重新審議，稱為「覆議」。
  3. C覆議由行政院向立法院提出，復議則是立法院自身的再審議。
  4. D覆議與復議均由行政院提出，差別在於議案性質。
  5. E覆議與復議均屬立法院內部的再審議程序。
顯示答案與解析隱藏答案與解析
答案　C　覆議由行政院向立法院提出，復議則是立法院自身的再審議。

覆議是行政院依憲政程序把立法院通過的案件送回立法院重行考量；復議是立法院內部對自己已作決議提出再議。題目辨識的是「誰向誰提出」，不能因兩詞同音而交換。

題 143 #

關於金融監理的工具模式，下列敘述何者錯誤？

  1. A命令與控制模式（the command and control model）強調「政府下令，不從就罰」，容易流於僵化
  2. B現代成文法立法時，常結合市場誘因模式（如碳交易市場、租稅減免）或自主管制（如企業社會責任、認證標章）
  3. C成文規範包括成文法，也包括非屬法律、但具實質約束力且以書面或文字表達的指導原則
  4. D金融法作為成文規範，僅涵蓋行政責任，不涉及民事責任與刑事責任
  5. E融斷機制、漲跌幅限制與融資券比例，屬於因應市場機制而生的市場工具（market-based instruments）
顯示答案與解析隱藏答案與解析
答案　D　金融法作為成文規範，僅涵蓋行政責任，不涉及民事責任與刑事責任

成文規範是一種監理工具，不會把法律效果限縮成行政責任。同一類金融違規在具備不同要件時，可涉及行政裁罰、對被害人的民事賠償，甚至刑事責任。命令管制、市場誘因與自律則是工具設計的不同面向。

題 176 #

依中央法規標準法，下列敘述何者為非？

  1. A法律應經立法院通過，總統公布
  2. B應以法律規定之事項，不得以命令定之
  3. C法律得定名為法、律、條例或通則
  4. D命令得牴觸法律，但不得牴觸憲法
  5. E法規對其他法規所規定之同一事項而為特別之規定者，應優先適用之
顯示答案與解析隱藏答案與解析
答案　D　命令得牴觸法律，但不得牴觸憲法

法律位階高於命令。依《中央法規標準法》第 11 條，命令不得牴觸憲法或法律，下級機關命令也不得牴觸上級機關命令。因此錯的是 D 所稱「得牴觸法律」。
